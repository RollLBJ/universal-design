# Generic design diagnosis

| Symptom | Replace with |
|---|---|
| every section is a rounded card | shared alignment, whitespace, separators; cards for genuine objects |
| huge welcome/hero on a task screen | actual task content and useful action |
| purple glow, beige, or glass by reflex | palette derived from brand, subject and audience |
| repeated icon-in-square decoration | purposeful icon, direct label or no icon |
| badge above each title | title first, metadata in plain text |
| wall of identical pill buttons | tabs, segmented controls, filters, radios or menu matched to selection behavior |
| equal emphasis everywhere | primary anchor and subordinate information |
| fake live label / activity / metric | sourced values, timestamp, or explicit sample state |
| text shrunk to fit | reflow, wrap, prioritize or disclose |
| hover or hidden swipe as only control | visible touch and accessibility alternative |
| desktop sidebar squeezed to phone | mobile stack, tabs or responsive navigation |
| rigid device mock frame in app | actual platform system chrome and safe areas |
| vague error or empty state | specific cause, actionable recovery, retained input |
| visual polish applied inconsistently | shared tokens and component variants |

Expressive elements are permitted when they serve the brief and maintain usability. Do not remove established brand expression merely because it resembles a common pattern. Evaluate the whole screen, not a mechanical count of cards. A deliberately dense professional workflow may need more controls than a consumer screen; organize them by importance instead of hiding functionality.
